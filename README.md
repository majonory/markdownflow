# MarkdownFlow Parser

## Короткий опис

**MarkdownFlow** — це парсер на основі Rust, який перетворює синтаксис Markdown у HTML-розмітку. Парсер обробляє текст Markdown і трансформує його у валідний HTML-вивід, що дозволяє відображати форматовані документи у веб-браузерах та інших середовищах, сумісних з HTML.

## Технічний опис процесу парсингу

- **Вхідні дані**: Синтаксис заголовків Markdown (наприклад, `# Заголовок`, `## Підзаголовок`, `### Назва`)
- **Вихідні дані**: HTML-теги заголовків (`<h1>`, `<h2>`, `<h3>` тощо)

### Механізм парсингу

Процес парсингу виконується у такі кроки:

1. **Токенізація**: Вхідний Markdown-текст сканується посимвольно для ідентифікації маркерів заголовків (символи `#` на початку рядка)

2. **Визначення рівня**: Парсер підраховує послідовні символи `#` для визначення рівня заголовка (1-6, що відповідає `<h1>` до `<h6>`)

3. **Вилучення вмісту**: Після ідентифікації рівня заголовка парсер вилучає текстовий вміст, що йде після символів `#` та пробілів

4. **Генерація HTML**: Вилучений вміст обгортається у відповідні HTML-теги заголовків на основі виявленого рівня

5. **Валідація**: Парсер перевіряє, що:
   - Маркери заголовків з'являються на початку рядка
   - Після символів `#` є принаймні один пробіл
   - Рівень заголовка не перевищує 6

### Як використовуються результати

Парсений HTML-вивід служить кільком цілям:

1. **Веб-рендеринг**: Згенерований HTML може бути безпосередньо вбудований у веб-сторінки для відображення в браузері
2. **Функціонал експорту**: Дозволяє експортувати Markdown-документи як HTML-файли
