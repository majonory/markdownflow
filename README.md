# MarkdownFlow Parser

## Короткий опис

**MarkdownFlow** — це парсер на основі Rust, який перетворює синтаксис Markdown у HTML-розмітку. Парсер обробляє текст Markdown і трансформує його у валідний HTML-вивід, що дозволяє відображати форматовані документи у веб-браузерах та інших середовищах, сумісних з HTML.

## Технічний опис процесу парсингу

Парсер аналізує чотири основні елементи синтаксису Markdown і перетворює їх у відповідні HTML-теги:

1. **Заголовки** (`#` до `######`) → `<h1>` до `<h6>`
2. **Жирний текст** (`**текст**`) → `<strong>текст</strong>`
3. **Закреслений текст** (`~~текст~~`) → `<del>текст</del>`
4. **Посилання** (`[текст](url)`) → `<a href="url">текст</a>`
5. **Курсив** (`_текст_`) → `<em>текст</em>`
6. **Зображення** (`![текст](img)`) → `<img src=\"img\" alt=\"текст\">`
7. **Цитатат** (`>текст`) → `blockquote>текст</blockquote>\n`

### Механізм парсингу

Парсер працює через просту перевірку початкових та кінцевих маркерів:

#### 1. Визначення маркерів

Функція перевіряє що рядок починається з певної послідовності (`#`, `**`, `~~`, `![`, `[`, `_`, `>`).


#### 2. Вилучення вмісту
Якщо формат коректний — вирізається контент між маркерами.

#### 3. Валідація
Перевіряється:
- рівень заголовка не більше 6
- маркери парні та закриті
- зображення містить текст і img (через схожу граматику зображення перевіряється раніше чим посилання)
- посилання містить текст і url

#### 4. Трансформація
Повертається HTML-рядок.  
Якщо формат невалідний — повертається вихідний рядок без змін.

### Як використовуються результати

Парсений HTML-вивід служить кільком цілям:

1. **Веб-рендеринг**: Згенерований HTML може бути безпосередньо вбудований у веб-сторінки для відображення в браузері
2. **Функціонал експорту**: Дозволяє експортувати Markdown-документи як HTML-файли
